This project is an attempt to make an open source VPN solution with state-of-the-art post-compromise and post-quantum security, as well as modern UX design and user friendly automatic configuration.

It is currently in a very early work-in-progress state and is subject to intense refactoring to prevent early technical debt. Do not use this software in its current state, it likely does not function and is not production-ready. This software will not be licensed until it has structure and function.
